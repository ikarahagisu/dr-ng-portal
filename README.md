# 当直NG入力（CSV提出方式）

データベースの契約・管理は不要です。既存のシフト作成アプリ本体は変更しません。

## GitHubから使う
1. GitHubで新規リポジトリを作成。
2. このZIPを展開し、app.py / calendar_ui.py / merge_requests.py / requirements.txt をアップロード。
   ZIPそのものではなく、中身のファイルを置いてください。
3. Streamlit Community CloudでGitHubに接続し、そのリポジトリを選んでアプリを作成。
4. 起動ファイルに app.py を指定。フォルダーごと置いた場合は dr_ng_portal/app.py を指定。
5. 発行されたURLを各Drに案内。
GitHubやStreamlitへのアップロード・公開はまだ行っていません。

## 各Dr
対象年月、医師名（管理者の名簿と同じ表記）、必要なら管理者指定の特別休日を選択。
翌日PM dutyとNG日を入力し「NG日を保存する」を押し、
「提出用CSVをダウンロード」してメール等で管理者へ送信します。
月間・横一列どちらのカレンダーも利用できます。
選択した色はその場で変わります。保存ボタンまでサーバーへNGを送信しません。
「保存」は開いている画面内での一時保存です。閉じる前にCSVをダウンロードしてください。
医師・年月・表示方式・曜日設定・特別休日を変える前に入力中のNGを保存してください。
ダウンロードされるのは最後に保存した内容です。

## 管理者
1. 既存シフト作成アプリの医師条件CSVを準備。
2. 本アプリの「CSVをまとめる（管理者）」画面で対象年月・特別休日を設定。
3. 元の医師条件CSVと、受け取った提出CSVを複数まとめてアップロード。
4. 作成された医師条件CSVをダウンロードして、既存のシフト作成アプリへ読み込む。
   特別休日も既存アプリで同じ日を指定してください。
NG日と翌日PM dutyだけを更新し、回数上限・希望日等は元のCSVを保持します。
未提出の医師は元の条件を保持します。
年月違い、医師名不一致、同じ医師の重複提出、特別休日の不一致はエラーで停止します。
提出状況の自動追跡・サーバーでの永続保存はありません。提出CSVを管理者側で保管してください。

## 手元で試す場合
    python -m pip install -r requirements.txt
    python -m streamlit run app.py

ブラウザーで http://localhost:8501 を開いてください。
